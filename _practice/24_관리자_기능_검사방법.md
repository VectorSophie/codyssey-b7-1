# 🟩 관리자 기능 검사 방법

## 🟢 백엔드 자동 검사

```bash
pytest -q
```

- `pytest`는 Python Test의 뜻으로 Python 테스트를 실행하는 도구다.
- `-q`는 Quiet의 약자로 결과를 짧게 표시한다.
- 외부 AI 요청은 테스트에서 차단하므로 OpenRouter 비용이 발생하지 않는다.

## 🟢 프론트엔드 타입 검사

```bash
cd frontend
npm run typecheck
```

- `cd`는 Change Directory의 약자로 `frontend` 폴더로 이동한다.
- `npm`은 Node Package Manager의 약자로 프론트엔드 도구를 실행한다.
- `typecheck`는 TypeScript 자료형 연결이 맞는지 확인한다.

## 🟢 프론트엔드 자동 검사

```bash
npm test -- --run
```

- `test`는 Vitest 테스트 명령을 실행한다.
- 첫 번째 `--`는 뒤의 선택 사항을 Vitest에 전달한다.
- `--run`은 파일 변경을 기다리지 않고 한 번 검사한 뒤 종료한다.

## 🟢 배포 파일 만들기 검사

```bash
npm run build
```

- `build`는 TypeScript와 React 소스를 브라우저가 읽는 배포 파일로 만든다.
- 성공하면 문법, 타입, 번들 생성 과정이 모두 통과한 것이다.

## 🟢 반드시 직접 확인할 상황

1. 비로그인 사용자가 `/admin`에 들어가면 로그인 화면으로 이동한다.
2. 로그인 성공 뒤 `/admin`으로 돌아온다.
3. 일반 사용자는 403 권한 안내만 보고 개인정보 표는 보지 못한다.
4. 관리자는 세 표와 전체 메시지 원문을 확인할 수 있다.
5. 검색어를 지우면 전체 행이 다시 보인다.
6. 로그아웃 뒤 뒤로 가기를 해도 관리자 API가 데이터를 반환하지 않는다.
